# Student Registration System

## About the Project
A simple web-based Student Registration System developed using HTML, CSS and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Student name and email collection
- Phone number validation
- Date of birth validation
- Gender selection
- Course selection
- Department selection
- Display submitted student details
- Clear Form functionality

## Project Files
- `index.html` – Registration form structure.
- `style.css` – Styling and layout.
- `script.js` – Form validation and functionality.

## How to Run
1. Download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Fill in the student details.
5. Click Register.
